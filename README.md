# Camp Chabelley WBGT

Prototype — not approved for operational decisions.

Open index.html or import this repository manually into Vercel as a static site. No build command is required; serve the repository root.

This initial scaffold provides an in-memory manual observation log and a simulated escalation timeline. Entries disappear on reload. No external requests, notifications, credentials, operational classification, authentication, database, durable audit log, or validated WBGT model are implemented. Do not enter sensitive or operational data.

The 5/10-minute escalation and 30-minute reminder intervals are proposed examples, not military requirements. Local policy, source verification, access control, durable storage, audit protection, provider integration, and tests remain to be implemented and approved. Vercel connection is left to the repository owner.
